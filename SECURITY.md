# Security Policy

## Reporting a vulnerability

If you find a security issue in the Zrzutka smart contract or web app, please **do not open a public issue**.
Open a private report via GitHub → *Security* → *Report a vulnerability* on this repository.

Please include:
- a description of the issue and its impact,
- steps to reproduce (transaction hashes or a test case if possible).

## Scope
- The Solidity contract in this repository
- The static web app (`index.html`)

## Notes
- The contract has **not** been audited. Use small amounts.
- Never share your seed phrase. The app will never ask for it.
