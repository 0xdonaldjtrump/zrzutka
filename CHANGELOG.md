# Changelog

## [1.0.0] — 2026-11-22

### Added
- `Zrzutka` contract: all-or-nothing campaigns in USDC on Base.
- Contributions with messages, EIP-2612 permit support.
- Claim with 1% platform fee (max 5%), refunds for failed/cancelled campaigns.
- One-time deadline extension, description/link editing, campaign updates.
- Upvotes, follows, reports and profile names.
- Soulbound Supporter NFT badges with on-chain SVG.
- Admin: fee, limits, pause, admin cancel, ownership transfer.
- Web app (PL/EN) with setup/deploy screen, EIP-6963 wallet picker, mobile layout.
- 8 contract test files and a Playwright end-to-end test.
